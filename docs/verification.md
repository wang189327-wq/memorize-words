# 1.1验证范围

验证日期：2026-11-08。安装包为1.1 / code2，应用ID `cn.ielts75.app`；公开包只含6张原创示例。后端功能版本独立为1.5.0。

## 本机已验证

- 28项Node规则/HTTP接口测试：旧备份、新schema2封装、FSRS确定性重放与时区、重复事件拒绝、评分/收藏合并、云接口与密码封装边界。
- 9组浏览器测试：实际IndexedDB失败与回滚、旧数据迁移、同书恢复后的陈旧标签拒绝、学习和复习、两隔离客户端评分同步、旧后端部分状态、离线子路径与失败更新、加密备份界面、剪贴板及CSP。
- 剪贴板四种组合均测试：纯单词、加序号、加释义、两者都加；保持书本顺序和一词一行。实际浏览器剪贴板读取及模态窗口内备用复制通过；原生桥接在浏览器中仅做契约模拟。
- 加密备份测试涵盖中文/空格/Unicode密码、随机salt与IV、规范化头、错误密码、篡改、未知字段、派生参数和体积上限；界面取消/不一致/下载/确认恢复/重开保留通过。
- Java干净构建及5项原生/SQLite测试：3项Robolectric迁移/事务/损坏旧文件恢复，2项更新缓存规则。它们是电脑端测试，未冒充真实设备。
- 格式、模块引用、Fork更新渠道、生成文件一致性和公开内容检查通过。生产依赖审计0项漏洞。
- 公开与仅本地的私人资源变体，分别核对包名、版本码、原签名、词卡数量和内嵌模块；私人词库及其封面不进入GitHub。

基准脚本 `node tools/benchmark-storage.mjs` 使用合成5470卡、50000条结果；单条追加只传输约262字节变更，旧完整快照约10.9MB。此数值是序列化载荷，不是手机磁盘耗时或提速保证。

## 审阅修复

独立审阅指出的3个问题已加入修复与回归：原生完整恢复走验证后清理旧文件的save路径；恢复/词库变化推进generation，拒绝陈旧标签写入；完整备份拒绝重复results.eventId。复制回退的textarea放入当前模态窗口，避免正文inert导致选取失败。

## 发布及外部边界

源码、网页版及安装包使用[仓库](https://github.com/wang189327-wq/memorize-words)和[1.1发布入口](https://github.com/wang189327-wq/memorize-words/releases/tag/v1.1-code2)，实际远端CI与线上核验结果以发布记录为准。历史v1.1已存在，所以使用v1.1-code2，不覆盖旧标签。

本轮未执行实体安卓安装器、手机/平板实际剪贴板、真实WebView密码恢复和厂商语音验收，也未向生产阿里云写入或部署。新评分协议需部署1.5同步包；未升级的旧后端会提示评分尚未同步。覆盖安装、系统权限和真实Tablestore需在对应设备/服务完成最终验收。

Windows中文路径下使用 `tools/build-android.py` 的英文临时目录构建。签名私钥、工具缓存和私人图书不属于公开源码。
