# 本轮验证范围

验证日期：2026-11-08。远端发布结果另见GitHub Actions及Release，本文件记录本机验证边界。

## 已实际完成

- Node规则及HTTP接口测试：16项，覆盖原创词库、非特定ID、第123分组、旧备份、学习队列、7/18词节点、收藏冲突、账号及分页。
- 浏览器测试：真实IndexedDB写入失败不提交状态、重试成功、重开保留、按数量学习、分组筛选、收藏区间、词库切换、390/800px宽度。
- 两个隔离浏览器客户端与本机真实HTTP服务、MemoryStore：收藏/取消互传、同步中新增、旧后端失败和重试；不使用真实账号或图书。
- 更新测试读取当前配置版本动态生成“新版本”，验证未配置时不请求服务器、完整清单传给原生及不可信地址拒绝。
- 格式、ES模块引用及公开资料边界检查。
- npm生产依赖审计：0项漏洞。protobufjs 7.6.6的SDK生成协议编解码和Tablestore客户端构造通过。
- JDK 21、Gradle Wrapper 8.11.1：干净构建调试APK和2项原生缓存测试通过。通过`tools/build-android.py`在临时英文目录验证，原中文源码目录保留。
